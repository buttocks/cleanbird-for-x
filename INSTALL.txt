CLEANBIRD FOR X 1.5.1

REQUIREMENTS
- Firefox
- Violentmonkey or Tampermonkey
- An existing X login in Firefox

INSTALL
1. Install Violentmonkey from:
   https://addons.mozilla.org/firefox/addon/violentmonkey/

2. Open Cleanbird-Firefox.user.js in Firefox.

3. Choose Install on the userscript-manager page.

4. Open or reload https://x.com/

SETTINGS
- Open X's More menu and choose Cleanbird settings.
- Or press Alt+Shift+C while viewing X.
- Or use the userscript manager's Open Cleanbird settings command.

BLOCKED COUNTERS
The top of Cleanbird settings shows totals for blocked ads, Grok/Chat clutter,
and tracking requests. Totals persist across reloads until Reset is selected.

The optional quick-settings button is disabled by default. When enabled, it
starts at the bottom-right, can be dragged around the screen edges, and
remembers its location. Use Reset quick button to bottom right in Cleanbird
settings to restore its default location. All cleanup and layout controls are
independent, so the interface can stay wide or compact as Firefox changes size.

CUSTOM APPEARANCE
Open Custom appearance in Cleanbird settings to choose separate PNG, JPG, WebP,
or SVG images for the header logo, browser tab/bookmark icon, Cleanbird's More-
menu icon, and the draggable quick-settings button. Each image can be returned
to its normal default independently. Images are stored locally by the
userscript manager and are limited to 3 MB each.

VIDEO FITTING
Fit videos to browser height is enabled by default. Oversized timeline videos
are scaled down so the complete frame fits within the browser viewport. Videos
that already fit are left at their normal size.

PRIVACY GUARD
Limit X tracking (best effort) is enabled by default. It blocks known X
client-event telemetry and beacons, removes common tracking parameters from
clicked links, and suppresses X as the referrer on external links. It is
conservative by design and cannot guarantee that every form of tracking is
blocked.

HOME TAB ORDER
Open X Home before opening Cleanbird settings. The Home tab order section detects the
tabs currently on X's top bar. Use the up and down arrows to place any tab where
you want it. New or renamed tabs remain visible and can be arranged later.
Choose Use X order to clear the custom arrangement.
For You is placed last by default. Moving it manually or choosing Use X order
turns off that default so the chosen order is respected.

UPDATING
Installing a newer Cleanbird-Firefox.user.js replaces the older version when
the userscript name and namespace are unchanged.

REMOVAL
Open Violentmonkey or Tampermonkey, find Cleanbird for X, and remove it.

PRIVACY
Cleanbird uses X's existing browser session. It does not ask for, copy, or store
your password and does not send analytics or personal data.
